# موج مانا

این پروژه یک وب‌سایت مدرن و اختصاصی برای ارائه خدمات مجالس ترحیم، پذیرایی، گل‌آرایی، میز یادبود و خدمات مرتبط است. هدف اصلی این پروژه، نمایش حرفه‌ای خدمات شرکت/تیم و فراهم کردن یک تجربه کاربری آرام، شفاف و امروزی برای بازدیدکنندگان است.

## این برنامه چه کاری انجام می‌دهد؟

وب‌سایت حاضر اطلاعات و خدمات زیر را به‌صورت منظم و جذاب نمایش می‌دهد:

- خدمات مجالس ترحیم و تشریفات مراسم
- پذیرایی و پک‌های پذیرایی
- حلوا و خرما
- گل‌آرایی و دکوراسیون
- میز یادبود و وسایل مرتبط
- خدمات مداح و قاری
- اطلاعات تماس و فرم سفارش/تماس

## ویژگی‌های اصلی

- طراحی مدرن و مینیمال با الهام از سبک لوکس و محترمانه
- پشتیبانی از زبان فارسی و جهت راست‌به‌چپ
- ساختار چندصفحه‌ای برای جدا کردن خدمات و اطلاعات
- بخش‌های قابل مشاهده مانند معرفی، خدمات، گالری، تماس و سفارش
- استفاده از استایل‌های سفارشی و Tailwind CSS
- تعامل و تجربه کاربری بهتر با انیمیشن‌های سبک و کارت‌های مینیمال
- بهینه‌سازی برای نمایش در موبایل و دسکتاپ

## چطور این پروژه را ساختیم

این پروژه با استفاده از تکنولوژی‌های ساده و قابل‌اعتماد ساخته شده است:

- HTML برای ساختار صفحات
- CSS و Tailwind CSS برای استایل‌دهی
- JavaScript برای بخش‌های تعاملی و بارگذاری بخش‌های مشترک
- تصاویر و فایل‌های استاتیک در پوشه src

ساختار کلی پروژه به این شکل است:

- src/index.html: صفحه اصلی
- src/*.html: صفحات جداگانه برای هر سرویس
- src/assets/style.css: استایل‌های سفارشی
- src/input.css و src/output.css: فایل‌های استایل Tailwind
- src/assets/js/include.js: منطق بارگذاری بخش‌های مشترک
- src/img: تصاویر پروژه

## چطور در محیط محلی اجرا کنیم

1. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```

2. پروژه را با یک سرور محلی اجرا کنید. برای مثال با Live Server یا:
   ```bash
   python -m http.server 8000
   ```

3. در مرورگر، آدرس زیر را باز کنید:
   ```text
   http://localhost:8000/src/
   ```

4. اگر در استایل‌های Tailwind تغییر ایجاد کردید، فایل خروجی را با این دستور به‌روزرسانی کنید:
   ```bash
   npx tailwindcss -i src/input.css -o src/output.css --watch
   ```

## مسیر توسعه در آینده

برای ادامه و رشد این پروژه، پیشنهادهای زیر مناسب‌اند:

- افزودن فرم سفارش واقعی و اتصال به پیام‌رسان یا واتساپ
- اضافه کردن پنل مدیریت برای ویرایش خدمات و تصاویر
- بهبود سئو و سرعت لود صفحات
- افزودن بخش رزرو آنلاین یا ارسال درخواست سریع
- پشتیبانی از چند زبان
- یکپارچه‌سازی با سیستم مدیریت محتوا یا دیتابیس
- بهینه‌سازی بیشتر برای دسترسی‌پذیری و تجربه کاربری

## جمع‌بندی

این پروژه یک نمونه خوب از یک وب‌سایت استاتیک حرفه‌ای برای خدمات مراسم و تشریفات است که هم از نظر ظاهر و هم از نظر ساختار، پایه‌ای قوی برای توسعه‌های آینده محسوب می‌شود.
